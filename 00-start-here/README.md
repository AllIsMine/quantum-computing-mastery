# Start Here

Welcome to **Quantum Computing Mastery**.

This repository is the curated learning, engineering, and research workspace for developing quantum computing expertise through mathematical understanding, practical implementation, systematic verification, and reproducible experiments.

## How to Use This Repository

1. Read the [Project README](../README.md) to understand the mission and research focus.
2. Review the [Master Roadmap](../ROADMAP.md) to understand the intended curriculum and project standards.
3. Follow the six-step learning cycle: **Understand → Predict → Implement → Verify → Modify → Investigate**.
4. Work on one active module at a time.
5. Test implementations, document results, and explain limitations before publishing completed work.

## The 200-Hour Quantum Computing Journey

The companion **200-Hour Quantum Computing Learning Track** documents the practical learning process that supports this repository.

**[Explore the 200-Hour Learning Tracker](https://github.com/AllIsMine/quantum-computing-200-hours)**

### How the Repositories Work Together

- **200-Hour Learning Tracker:** Daily learning records, practice exercises, ongoing experiments, and progress documentation.
- **Quantum Computing Mastery:** A curated portfolio of refined, tested, documented, and reproducible projects and research deliverables.

The learning tracker preserves the learning process. The Mastery repository presents selected work that has been improved and validated.

## Learning Principles

- Understand the mathematics behind implementations.
- Predict expected results before running experiments.
- Verify correctness with analytical checks and appropriate tests.
- Record software versions and experimental settings.
- Distinguish simulator results from real quantum hardware results.
- Report uncertainty, assumptions, and limitations honestly.
- Advance based on demonstrated understanding rather than completion alone.
