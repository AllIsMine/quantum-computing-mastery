# Quantum Algorithms and Protocols

This module explores important quantum algorithms and communication protocols, connecting mathematical principles to circuit implementations and verified computational results.

## Planned Topics

- Deutsch–Jozsa algorithm
- Bernstein–Vazirani algorithm
- Grover's search algorithm
- Quantum Fourier transform (QFT)
- Quantum phase estimation (QPE)
- Quantum factoring concepts
- Quantum teleportation and superdense coding connections
- Algorithm correctness and resource analysis
- Classical comparisons and limitations

## Learning Method

Each topic will follow the Quantum Computing Mastery learning cycle:

1. Understand
2. Predict
3. Implement
4. Verify
5. Modify
6. Investigate

## Practical Work

Python implementations, quantum circuits, mathematical derivations, independent exercises, automated tests, and experiment reports will be added progressively as the material is developed and validated.

Where relevant, projects will document circuit depth, gate counts, measurement statistics, simulation settings, and comparisons with classical approaches.
