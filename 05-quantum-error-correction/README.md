# Quantum Error Correction

This module explores how quantum information can be protected against errors and how error-correcting codes support reliable quantum computation.

## Planned Topics

- Sources of quantum errors and decoherence
- Classical coding theory foundations
- Quantum bit-flip and phase-flip errors
- Quantum repetition codes
- Shor and Steane codes
- Stabilizer formalism
- Syndrome measurement and error diagnosis
- Logical qubits and fault tolerance
- Surface-code fundamentals
- Quantum error-correction experiments using Stim, PyMatching, and Sinter

## Learning Method

Each topic will follow the Quantum Computing Mastery learning cycle:

1. Understand
2. Predict
3. Implement
4. Verify
5. Modify
6. Investigate

## Practical Work

The module will progressively include mathematical derivations, circuit implementations, simulations, automated tests, decoder comparisons, and reproducible experiments.

Results will distinguish idealized demonstrations from realistic noise models, and assumptions and limitations will be documented explicitly.
