## Status Definitions

- **Planned** — Scope is defined, but substantive implementation has not yet started.
- **In Progress** — Substantive learning material, code, exercises, or experiments are being developed.
- **Validated** — Completion criteria have been met, relevant code and tests pass, results and limitations are documented, and the material is considered ready for use by others.

> A directory or README file alone does **not** qualify a module as validated.
